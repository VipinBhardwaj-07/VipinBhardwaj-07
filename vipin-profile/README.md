### 01 · AlgoVerse — Interactive DSA Learning Platform

<a href="https://algoverseweb.xyz/"><img src="assets/card-algoverse.svg" width="100%" alt="AlgoVerse project preview"/></a>

**A DSA learning platform that turns abstract algorithms into things you can see, run, and practise.**

[![Live](https://img.shields.io/badge/Live_Website-25DCCB?style=for-the-badge&logo=googlechrome&logoColor=white)](https://algoverseweb.xyz/)
[![Source](https://img.shields.io/badge/Source_Code-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/VipinBhardwaj-07/AlgoVerse)

</div>

| 🎯 **Problem** | 💡 **Solution** |
|---|---|
| DSA is hard to learn from static text — you can't *see* how an algorithm moves. | Interactive visualizations, structured course pages, quizzes, and an AI tutor in one place. |

**What's inside**

- 📚 **Full course pages** — Data Structures (15 modules, 78 topics), Graph Algorithms (12 modules, 55+ topics), and Dynamic Programming
- 🎬 **Algorithm visualizations & SVG diagrams** with real-world examples
- 🧩 **Practice tools** — challenge consoles with difficulty-tagged exercises, MCQ quizzes, "Interview Ready" sections
- 🤖 **Vera, an AI tutor** — chatbot powered by the Anthropic API with voice input, markdown replies and quick-topic chips
- 📈 **Progress tracking**, collapsible sidebar navigation, and a responsive mobile layout
- 🔐 Authentication and backend-powered features

**Tech:** `HTML` `CSS` `JavaScript` `Node.js` `Express.js` `MongoDB` `Anthropic API`

### 02 · Supermarket Sales Analysis — Data Analytics

<a href="https://github.com/VipinBhardwaj-07/Supermarket-Sales-Analysis"><img src="assets/card-sales.svg" width="100%" alt="Supermarket Sales Analysis project preview"/></a>

**Exploring transaction patterns and customer behaviour through visualization and machine learning.**

[![Repo](https://img.shields.io/badge/Explore_Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/VipinBhardwaj-07/Supermarket-Sales-Analysis)

</div>

| 🎯 **Goal** | 🔬 **Method** | 📊 **Result** |
|---|---|---|
| Understand what drives sales and how customers group by spending. | Cleaning → EDA → Linear Regression → K-Means clustering | R² = **0.891**, MAE = **54.43** sales units, **3** spending segments |

- Analysed **1,000 synthetic transaction records**
- Built **9 visualizations** covering product, sales, and customer trends
- Completed as part of the **IBM SkillsBuild** data analytics programme

> ℹ️ *The dataset is synthetic. Metrics describe this project's data and are not validated business forecasts.*

**Tech:** `Python` `Pandas` `NumPy` `Matplotlib` `Seaborn` `Scikit-learn` `Jupyter Notebook`
