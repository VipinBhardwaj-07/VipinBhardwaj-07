### [Supermarket Sales Analysis](https://github.com/VipinBhardwaj-07/Supermarket-Sales-Analysis)

An end-to-end data analytics and machine learning project examining sales patterns and customer behavior using a reproducible, synthetically generated dataset of 1,000 transactions.

- Prepared data and performed exploratory analysis across products, branches, customer types, and shopping times.
- Created nine visualizations to communicate sales and customer trends.
- Applied linear regression for sales prediction and K-means clustering for customer segmentation.
- Included an executed Jupyter notebook, reusable scripts, and a project report.
- **Technologies:** Python, Pandas, NumPy, scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

### [CNN Image Classification — Cats vs. Dogs](https://github.com/VipinBhardwaj-07/CNN-Image-Classification)

A computer-vision project using a convolutional neural network (CNN) for binary image classification.

- Implemented image preprocessing and model training with TensorFlow/Keras.
- Added a prediction script for custom images and accuracy/loss visualizations.
- The repository reports **90%+ training accuracy**; this figure is training performance, not a validation or test-set result.
- **Technologies:** Python, TensorFlow, Keras, OpenCV, NumPy, Matplotlib
